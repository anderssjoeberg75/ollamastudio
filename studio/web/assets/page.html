How to train your own model – in five minutes

"Training" here means taking an existing base model and showing it your own examples, so it responds the way you want. No programming required – simply follow the steps below from top to bottom.

  1. Data. Enter 20–200 question-and-answer examples in the table (or point to an existing .jsonl file). Click Generate sample data to test the flow first.
  2. Model & method. Choose a base model (start small – 0.5B or 1.5B) and a hardware profile matching your GPU. The rest is configured for you.
  3. Train. Click Start training and follow the progress. The base model is downloaded on the first run, which may take a few minutes.
  4. Use the model. Click Import into Ollama once training completes. The model will appear under My Models and in the chat.

How long does it take?

  • 50–200 examples + a 0.5–1.5B model on a dedicated GPU: a few minutes.
  • The same dataset on a 7–8B model: 30 minutes to a few hours.
  • CPU only: expect hours – choose the smallest base model and 1 epoch.

How should data look?

The simplest approach is the table in step 1: one row per example with question and answer. It saves as JSONL in alpaca format:

{"instruction": "What is the capital of Sweden?", "input": "", "output": "Stockholm."}

If you already have data, these formats are also supported (automatically detected):

chatml:   {"messages": [{"role": "user", "content": "Hi"}, {"role": "assistant", "content": "Hello!"}]}
sharegpt: {"conversations": [{"from": "human", "value": "Hi"}, {"from": "gpt", "value": "Hello!"}]}
dpo:      {"prompt": "Explain gravity", "chosen": "Good answer…", "rejected": "I do not know"}

Tips for best results

  • Quality beats quantity. 100 well-crafted examples beat 1,000 messy ones.
  • Be consistent. Write answers in the tone and length you actually want.
  • Start small. Run a small model first to verify the full flow into Ollama, before launching a large run.
  • Facts are learned best with diverse phrasings – ask the same question in multiple ways.

Troubleshooting

  • Out of GPU memory: Choose a smaller base model, lower context length, or the profile for smaller GPUs (4-bit + layer offloading).
  • "Gated repo" / 401: The base model requires agreement on Hugging Face. Accept the terms there and enter an HF token in ⚙ Settings – or choose an open model (without ⚠ in the list).
  • Soup missing: Click Install Soup in the status bar, or run pip install "soup-cli[train]" on the server.

Training is powered by Soup (soup-cli), an open source CLI tool. Ollama Studio handles forms, progress monitoring, and import into Ollama.

🎓 AI Training (fine-tune custom models)

The AI Training tab lets you fine-tune a model on your own examples and import it into Ollama. Training execution is performed by Soup (pip install "soup-cli[train]"), installed separately on the server. Requires an access token if the server is exposed to others – training writes to disk and spawns processes.

Codex (coding agent)

A coding agent that reads a project folder, edits files, runs tests, and interacts with git – powered by your own Ollama models. Configure autonomous actions under Permission below: ask permission every step, edit files automatically, or full autonomy. Every file write can be undone. Works strictly inside the selected folder.
